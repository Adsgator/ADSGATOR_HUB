## 6. COMPONENTES UI - ESTADO & CORES

### Status Badges

```
🟢 Ativo              ← Tudo ok
🟡 Atenção            ← Ação necessária
🔴 Crítico/Urgente    ← Problema eminente
⚪ Congelado          ← Em espera (cliente)
⚫ Arquivado          ← Inativo
```

### Priority Pills

```
[🔴 Urgente]    - Ação necessária hoje
[🟡 Atenção]    - Esta semana
[🟢 Normal]     - Próximas semanas
[⚪ Baixa]      - Quando tiver tempo
```

### Action Buttons Pattern

```
Primária:      [🚀 Ação Principal]     (Amarelo Ads, texto branco)
Secundária:    [Ação Secundária]       (Border only)
Destrutiva:    [🗑️ Deletar/Arquivar]   (Vermelho)
Ghost:         [Visualizar]            (Hover effect)
Icon:          [🔄]                    (Só ícone)
```
